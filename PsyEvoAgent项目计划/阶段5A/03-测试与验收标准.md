## 对照与指标口径

使用02定义的MA-A/B/C/E，同一任务配对、同一数据版本/模型族/角色模型映射、同一权限和工具、同一总预算。MA-A保留单Agent既有RAG与Memory服务能力；MA-D只在配置开启且来源有效的同一分层与MA-C比较，不额外授予私人信息或隐式确认。结果按简单支持、事实检索、复杂回答、固定风险场景、记忆候选分层，同时给总分母；不强制A浪费预算配平实际成本。

| 指标 | 预先冻结的计算与记录规则 |
|---|---|
| 支持质量、事实/感受区分 | 沿阶段5固定0/1/2维度及独立审阅；报告每维有效评分数、缺失、分歧和严重反例，不以单一均值覆盖硬失败 |
| 引用正确率 | 正确支持相应论断且输出时可访问的引用数/全部输出引用数；另外报告应引用但未引用的论断；无引用任务标N/A，不给100% |
| RAG groundedness | 在需要知识支持的任务中，被有效检索证据支持的可核验论断比例；采用阶段5固定标注/经校准工具，报告无证据任务、失败和分母 |
| 严重错误、权限错误、Tool错误 | 分类别计数及每run发生率；Tool错误另报每执行次数；泄露、越权、删除复活、重复副作用和固定安全违规是硬失败，不用均值抵消 |
| 不必要Agent调用率 | 独立场景标注下不需要的角色调用数/实际角色调用数，另报受影响run比例；不能由当前routing_policy自定义正确答案 |
| Reviewer修正有效率 | 原稿存在独立确认错误，Reviewer指出且修订稿消除该错误、未新增严重错误的案例数/原稿确有错误且完成复核的案例数；Reviewer漏检和修订失败计失败，未完成另报 |
| Reviewer误拒率 | 独立审阅合格的原稿被Reviewer错误判为revise或block的案例数/独立审阅合格且完成复核的原稿数；revise/block分别列数 |
| token、cost、调用 | 逐角色、逐run记录所有实际调用和重试；报告预占/实际/未知，未知费用不记零；evaluator成本另列且同口径 |
| P50/P95 latency | run从实际start到真实终态的墙钟分布，按组合分层；HITL含等待总耗时与活跃执行耗时分开；失败/超时/取消另列分布及数量，不静默丢弃 |
| failure rate | 非用户主动取消且未完成预定任务的run数/（已启动run数－用户主动取消数）；同时报告总启动数、取消数和取消率；降级、部分结果、错误、超时分别列出，降级成功不伪装为原组合完整成功 |

所有分母为0的指标标N/A。配对差异、样本数、不确定性和实际成本均保留；正式阈值、重复次数、预算profile与holdout读取次数在看结果前冻结。角色Reviewer不担任独立评分器，优化器不得逐轮读取holdout反馈。与阶段7RSI-A/B/C不同，这里的MA组只比较角色执行组合。

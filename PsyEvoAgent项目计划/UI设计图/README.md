设计交付记录日期：2026-09-23；历史检查针对静态图片，不是产品验收。

参考基线：**B｜功能优先**。本仓库包含29张页面参考图、Logo和favicon；允许结合实际功能与使用便利性改进设计，不要求死板复刻。

## 参考使用原则与合同优先级

图片用于理解产品气质、信息层级和操作路径，不要求像素级复刻。可以为更少操作、更清楚的状态、响应式和无障碍改进设计；保持品牌辨识与学生端四个一级入口，在所属阶段实施记录中简述重要差异及理由，无需为普通视觉调整增加审批流程。

业务行为以[内部实验执行约定](../../EXPERIMENT.md)和各阶段02当前合同为准；01维护页面目标，03维护验收要求，04引用并执行。图中文字、演示数值、角色和按钮不新增API、权限、功能范围或发布授权。图片已完成、功能已实现和业务已验证分别记录。

| 参考中的差异 | 实施口径 |
|---|---|
| P03只有邮箱、密码，含“创建即表示已阅读”文案 | 按[邮箱身份目标](../阶段1/02-技术方案与实施计划.md#email-identity-target)补验证码；校验通过才创建账号。不将注册记为用户同意，不增设年龄或逐用途确认 |

## Brand

- 品牌性格：清楚、可靠、克制；把表达、整理和用户控制放在主要位置。
- 图形理念：两枚错位的开放折片构成可打开的记录空间，表达承接、回看与用户控制。图形不使用医疗、机器人或拟人化陪伴符号。
- Logo：[PsyEvoAgent-Logo.png](品牌/PsyEvoAgent-Logo.png)，1024×1024透明 PNG。
- favicon：[favicon.png](品牌/favicon.png)，512×512透明 PNG；沿用同一轮廓，已检查16、32、48px辨识度。
- 图形与 `PsyEvoAgent` Wordmark 横向组合：界面内图形约24px，间距8px，字标20px/600；只放一次，不重复压过页面标题。
- 图形周围至少保留其宽度四分之一的安全空间。favicon仅使用图形，不放英文全称。禁止拉伸、旋转、加光晕或改成医疗标志。

## Design System

以下为建议的设计基线；颜色、字号、间距和布局可为可读性、响应式或操作便利性调整，保持清楚、可靠、克制的整体方向。不声称生成图片包含可提取的原始 CSS 或嵌入字体。

| 颜色角色 | 值 | 用途 |
|---|---|---|
| Primary | `#2579C6` | 主操作、链接、当前选择 |
| Secondary | `#3B647B` | 次级强调 |
| Accent | `#E5F0FB` | 选中背景，限制使用面积 |
| Background | `#F7F9FC` | 页面外围背景 |
| Surface | `#FFFFFF` | 正文、表单、表格 |
| Sidebar / Message | `#F1F3F6` / `#EEF2F6` | 分栏与消息层次 |
| Text / Muted | `#172033` / `#667085` | 正文与次级说明 |
| Border | `#E2E7EF` | 必要分隔线 |
| Danger / Success / Warning | `#B42318` / `#287553` / `#946200` | 局部语义状态，始终配文字 |

中文字体目标为思源黑体／Noto Sans SC，西文为 Inter；字号、日期和表格保持清晰，品牌不使用文学海报式大宋体。

| 文字层级 | 字号／字重／行高 |
|---|---|
| Display | 40–44 / 600 / 52，仅公共页面 |
| H1 | 24 / 600 / 34 |
| H2 | 20 / 600 / 28 |
| H3 | 18 / 600 / 26 |
| Body | 16 / 400 / 26 |
| UI | 14 / 400–500 / 20 |
| Caption | 12 / 400 / 18 |

- Spacing：4、8、12、16、24、32、48px；正文内边距28–32px。主导航192px，会话列表224px，正文最大约720px。
- Radius：按钮和输入6px，消息、Composer与局部卡片8px，浮层10px。Border为1px；常规页面无投影，仅浮层轻阴影。
- Button：36px高；主、次、文字、危险和禁用状态。只有当前任务的主要动作使用实心主色。
- Input／Textarea／Select：输入40px高，Composer约112px；标签始终可见，聚焦时有清楚边框；空消息不可发送，错误紧邻字段。
- Tabs／Chip／Badge：紧凑，状态配中文文字；分类、状态、模式各自分层，不让全部标签争夺注意力。
- Card／List／Table：只为独立对象使用卡片；列表按真实内容长度组织；表头32px、数据行40px，按需详情抽屉承接正文与审阅。
- Drawer／Modal：仅用于相关详情、确认或找回密码，具有标题、关闭和清楚的主要操作；不把每个动作都变成弹窗。
- Tooltip／Dropdown：解释图标、放次级操作，不能藏起现实支持或关键数据控制。
- Skeleton／Empty／Error：加载不冒充完成；空态给出当前可做的下一步；错误保留输入并提供合理重试。
- Icon：统一18px细线图标；只在帮助识别时使用，不用机器人头像或AI星星。焦点轮廓与可点击区域不得为视觉克制而消失。

## 公共页面原则

官网、登录与注册共享品牌、字体和控件。官网以具体场景和产品界面解释对话、记录、回顾、资料与记忆控制，不虚构人数、合作、认证或疗效。

目标注册先验证邮箱验证码，普通登录使用邮箱＋密码，不收用户名、学校、手机号或心理情况。忘记密码采用“输入邮箱→发送验证码→输入验证码与新密码→重置成功→返回登录”；登录后改密按阶段1合同校验当前密码。找回、改密及错误状态不受29张图片数量限制。2026-09-23邮箱身份代码已接入；现有页面采用本设计的蓝白品牌，注册增加验证码和重复密码，不照搬图片中的旧阅读确认或未实现导航。实际验证见[STEP03.5记录](../阶段1/evidence/S1-STEP03/email-identity/README.md)。

## 学生端原则

完整学生端一级导航为“对话／我的记录／支持资源／我的”；登录后直接进入已实现功能，对话完成后再作为主入口。记录与对话分开管理，主动带入记录、行动修改和回顾按所属阶段合同执行。记忆提取校验后自动保存，保留推断标识，提供查看、更正及确认删除。现实支持入口在相关功能实现后稳定可见。

无诊断评分、疾病概率、依赖总分、签到激励或情感留存；不展示 Agent、Prompt、Token、路由与内部推理。未核实的现实资源使用空态，不虚构电话、机构或值班信息。

S01、S15、S16展示不同阶段的视觉状态，不代表当前账号实际能力。experiment-defaults/1与implemented分列：默认配置开启不等于功能已实现，也不生成用户同意记录；图片中的开关、待确认或未开放状态不能覆盖当前实验约定。

## 工作台原则

导航为“内容／任务／反馈／评估／运行／版本／优化／研究”。审阅和索引分列，列表优先显示中文状态；缺失指标显示“暂不可用”。私人正文默认隐藏，反馈仅含主动提交信息，Trace采用时间线与调用结构。

版本发布需要人工审批；优化最多批准进入预发布；隔离研究不自动进入生产。运行、评价、版本和研究数值只作为明确标注的合成示例，不代表已实测结果。

资源中的标题、版本和审阅日期为本任务指定的演示内容，不证明已获得真实专业审核。可核验来源参考为 [CCI Assertiveness](https://www.cci.health.wa.gov.au/Resources/Looking-After-Yourself/Assertiveness)；自拟交流范例不冒充该机构原文，也不能用来证明用户处境。
